# 📊 Global YouTube Statistics Dashboard (Power BI)

## 📌 Project Overview

The **Global YouTube Statistics Dashboard** is a Power BI project built using a **Global YouTube Statistics Dataset**. The dashboard provides an interactive analysis of YouTube channels based on views, subscribers, uploads, categories, estimated earnings, and country-wise performance.

The primary objective of this project is to transform raw YouTube statistics into meaningful insights through **data cleaning, data transformation, KPI generation, and interactive visualizations**. The dashboard allows users to explore top-performing YouTubers, identify popular categories, compare channel performance, and analyze global YouTube trends.
